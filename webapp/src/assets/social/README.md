# Social icons

Brand marks for the share dialog, downloaded from
[Simple Icons](https://simpleicons.org) (CC0 1.0). Each file is the 24×24
glyph for the network; `NetworkIcon` fills it with the platform's official
brand colour, so it stays recognisable beside the link label.

The LinkedIn mark is the last version Simple Icons published before it was
removed upstream in December 2024.
