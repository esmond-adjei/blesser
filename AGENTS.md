# Agent notes

UI work follows the design system in `design-system/reference/README.md`. Build with `@blesser/ui` components and its tokens (`bg-surface`, `text-ink`, `shadow-elevation-1` and so on), never raw colours.

Copy rules: no middle dot separators and no em dashes (a plain dash only in date ranges), and never show the same fact or action twice in one component. Every screen must work at phone width.
