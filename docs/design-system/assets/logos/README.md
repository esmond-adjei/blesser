The Graduator mark: mortarboard over a magnifying glass, with a gold compass needle in the lens. Copied from the repository, never redrawn.

- `logo-dark.svg`: navy ink (`#10325e`) with gold needle and mist paper. For light grounds (`canvas`, `surface`). Despite its name, this is the one for light mode.
- `logo-light.svg`: light ink (`#e5f3ff`) with gold needle. For dark grounds and `brand` fields.
- `favicon.svg`: the browser-tab mark.
- `logo.png`: 512px navy mark on transparent, for PDF exports and email.
- `logo-on-navy.png`: 512px light mark on transparent, for placing on `brand` (the app icon tile adds the navy behind it).

Each is a fixed-colour image: it does not follow `currentColor`. In the app, inline the SVG so its ink can follow `label`.
