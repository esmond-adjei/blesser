Gradis, the assistant's penguin, as sticker art cut from the Graduation Mascot sticker grid. Full-colour PNGs (navy, gold, white) that read on both themes.

Use by situation, at 112px tall in empty states (80px when compact). The app's chat launcher is a separate 72px animated Gradis (`webapp/public/mascots/`, via `page-mascot`), not one of these stickers:
- `happy.png`: a run finished, a draft approved.
- `reading.png`: agents at work.
- `search-empty.png`: a search or filter with no results.
- `empty-box.png`: nothing created yet.
- `not-found.png`: a missing page or record.
- `no-file.png`: no CV uploaded.
- `offline.png`: no connection.
- `loading.png`: a long wait.
- `error-gear.png`: something broke on our side.
- `gradis.svg`: the head mark for the chat button and avatar.

Alt text describes the pose ("Gradis searching with a magnifying glass"). One Gradis per screen.
