# Logo

The Graduator mark is a mortarboard over a magnifying glass whose lens holds a gold compass needle: searching, guided.

Use the files in the Logos asset group, never a redrawn mark. On light grounds use the navy-ink file, on dark grounds the mist-ink file; in the app the mark is inlined so its ink follows `label` while the needle stays `gold`.

Lockup: mark plus the word "Graduator" in Instrument Sans 600 at -0.03em, the word's cap height about 45% of the mark, gap of 0.25 mark widths. Clear space on every side is half the mark's width. Minimum size 20px for the mark alone, 96px wide for the lockup.

The navy tile (`logo-on-navy.png`) is the app icon and social avatar: mark on `brand`, corners at 23% of the side.

Don't: recolour the needle, put the navy mark on `brand`, add effects, or set the wordmark in the serif.
