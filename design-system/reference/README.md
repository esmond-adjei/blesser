# Design system reference

A copy of the Blesser design-system artifact (https://claude.ai/artifact/XfwDvqhmaHGjyVzq3SvAWk), the source of truth for how the product looks.

- `project/README.md`: the guidelines. Read it before building or restyling any UI.
- `project/tokens.json`: the artifact's tokens. The code's tokens live in `../tokens.json` and are built into CSS with `npm run tokens`; keep the two in step.
- `project/assets/Logos/README.md`: logo usage.

Component specs and layout previews (`project/components/`) are not tracked. Download them from the artifact into that folder when you need a screen's reference layout.
